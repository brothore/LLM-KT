## 能否得到原来的结论

原稀疏验证集整体AUC依次为B0=0.737549、R1=0.767998、R2=0.798241、R3=0.766847。本次R2仍在整体AUC上最高，支持“R2在当前开发集的整体排序最好”这一局部观察；但完整排序没有完全重现：旧版R1略高于R3，本次R3明显高于R1。

学生指标则应单独判断。本次R3的学生平均AUC高于R2约0.023459，并且4名学生各自都是R3高于R2。不能笼统宣布R2为所有KT指标上的最佳方案。R2相对B0整体AUC提高0.103521，学生均值提高0.145614；R3相对B0整体AUC提高0.096438，学生均值提高0.169073。
