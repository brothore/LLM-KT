# 正反问法融合：结果与阶段交接

## 结论

两轮完整验证没有显示正反融合能超过各模型更好的单向整体AUC。Qwen保持原正问方案；Jev保持原反问方案。Jev融合的Log loss/Brier有小幅改善，但整体AUC和学生mean均低于反问，且每目标请求数翻倍，因此不设为默认。

用户授权人民币3元；同4学生492完整目标，两模型各两轮正反配对，共8组3936条成功预测。没有用当前/未来答案生成请求或拟合融合权重；历史均为真实过去作答。模型、提供商和模板在两轮之间固定，第二轮反转正反执行顺序。

## 思想、公式与解释

令a为正问的答对概率，b为反问的答错概率。比较算术p=(a+1-b)/2、主方法p=sigmoid((logit(a)-logit(b))/2)、附加方法p=a/(a+b)。主方法在两问共享相同logit加性yes偏移时可以抵消该偏移；这一假设并不由两次观测自动成立，不能称真正无偏。完整推导、数值边界和论文启发见[实验设计](正反问法对称融合实验.md)。

Qwen使用自报四位小数概率；Jev使用原生noul。未提取Qwen的yes/no token logits，所以本结果不等于否定token级校准方法。正反两问的合法事实相同，模板只更换事件表达及输出方向；不在同一对话中相互提示。

固定偏移未必改变AUC，可能主要影响校准。实际观察到：Qwen平均绝对正反分歧约0.0801/0.0805，Jev约0.0440/0.0436；分歧可重复，但不能识别其中有多少来自偏好、语义误差或普通预测误差。互补性不保证真实准确率。

## 完整性与恢复

Qwen首轮反问初次488/492、21次超时未知费用，单独补试4目标后完整；中间一次旧恢复入口为0新请求，其记录保留。Jev第二轮正问初次491/492、HTTP529未识别为可重试，测试修复后只补1目标。成功记录未重跑，旧失败记录未重写。其他失败在原重试限制内恢复。

恢复参数retry_failed_once默认关闭，只允许限定传输失败额外一次，HTTP529使用剩余常规尝试额度；新增测试覆盖成功缓存不变、失败补试有界和529重试。全套60项测试通过。源码、原配置、变更、恢复计划和invocation分别留存。
