## Tenstorrent 是否更便宜

同样的历史与当前题，分别固定 Tenstorrent fp4 与 Chutes fp8，四次请求含三条连续目标及一次重复对照：

| 端点 | 合计报告费用 USD | 各次 cached_tokens |
|---|---:|---|
| Tenstorrent | 0.000150340 | 0、2432、2432、2496 |
| Chutes | 0.000273080 | 0、1600、1600、1600 |

这组样本 Tenstorrent 更便宜，因此后续全部完整迭代固定使用 Qwen3.8 27B / Tenstorrent，没有中途混入其他端点。不同供应商使用不同量化，价格判断不等同于质量等价。

Tenstorrent 原始回复是单层 Markdown JSON 围栏。最初严格解析拒绝，原始失败记录保持不变；补充受限格式正规化后，离线重读四次响应均可得到合法概率，没有再次付费重发。正规化只接受完整裸JSON或单层围栏内的完整JSON，仍拒绝额外解释、额外字段、非数值或越界概率。

## 协议与选择规则

NIPS 0.1% 目标子集，question 级 pykt_window，maxlen=200，最多199条合法历史；下一步使用此前真实作答，不使用上一题预测概率更新历史。

所有候选在完全相同的 fold0 验证集221目标、179学生上完整运行；主要目标为整体 AUC，logloss 用于相同 AUC 的平局判断。学生级指标同时记录，但只有16名验证学生具备双类目标，不能用其均值代替整体目标。

B0使用通用任务说明与紧凑历史在前JSON，是本轮实验基线；默认生产适配器的布局未随之替换。R1、R2、R3仍保留完整原历史，没有以减少token为设计目标。

第二、三轮的题目/知识点先验只取原数据训练fold1–4：3148名学生、887776次作答；排除fold0的787名学生，不读取测试标签，平滑强度20。它属于训练信息增强，不是单纯的提示措辞变化。

## 测试前锁定与独立检验

三轮结束后、运行测试前，将R2的选择依据及四份验证报告哈希固化到 `runs/prompt_iterations_20261018/selection/`，其中明确 test_results_used=false。之后只运行选定R2与预先约定的B0对照各一次，不再按test结果挑选R1/R3或继续改prompt。

R2测试AUC相对基线为 **−0.010858**。ACC和logloss改善，Brier和AUC未改善；用户优先要求AUC，因此不能按辅助指标宣称成功。

按学生聚类、相同重采样索引的2000次配对bootstrap，测试AUC差的探索性95%分位区间约 **[−0.05362, +0.03188]**，包含0。这既不足以证明AUC提升，也不足以认定该小幅回退稳定存在。验证集差的区间约[+0.01428,+0.10783]，但它参与了prompt选择，不能作为独立显著性证据。

## 实现与复现入口

- `src/llm_kt/prompts.py`：版本化渲染、合法历史统计和冻结的训练先验读取。
- `src/llm_kt/budget.py`：每次请求前保守预留、响应结算、未知费用保留。当前编排逐个启动run，同一run内并发8；不要多进程同时写同一预算文件。
- `model.prompt_file`：prompt文件加载后冻结到运行配置；不作为未知API参数发送。
- `configs/prompts/`：B0与R1/R2/R3完整文本。
- `configs/experiments/`：验证、基线测试和选定候选测试配置。
- `tools/build_prompt_priors.py`：仅从训练fold生成先验。
- `tools/run_prompt_experiment.py`：复用infer、evaluate、verify-run执行完整单轮。
- `tools/analyze_prompt_experiment.py`：离线概率与分组诊断。
- `tools/paired_auc_interval.py`：按学生配对bootstrap。
- `tools/recover_prompt_run.py`：离线恢复已返回响应，不额外调用API。

完整本地产物在 `runs/prompt_iterations_20261018/`，先验在 `data/processed/prompt_priors_fold0/`。输入、响应、概率、指标、每次调用身份、源码及价格指纹、样本映射与费用均保留；Git只保存代码、配置和不含个人信息的统计文档。

## 决策与下一步

完成至少三轮AUC迭代的要求，保留全部成功与失败候选。R2仅是验证集选择出的研究候选，未替换默认prompt；测试未观察到AUC增益，因此暂不开始以它为基础的token压缩。
