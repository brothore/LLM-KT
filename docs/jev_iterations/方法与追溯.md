# Jev多轮适配方法与追溯

本阶段预算人民币3元，按1美元=7元作预算换算；已知收费加未知请求预留不得超过3元。独立账本runs/jev_iterations_20261018_v1/budget.json，不释放此前Qwen阶段未知费用。保持4名学生492个完整评价目标，序列原长度86/97/146/167，每人从第2条开始评价；使用此前真实作答，不递归输入预测。

## 模型与适配

固定typesafe/jev-1.14、TypeSafe提供商、关闭fallback，通过Decisions API问一个二元noul问题。Jev模板独立于Chat模板。题目和知识点是无语义ID，禁止凭ID编造题目文本。模型仅见允许的历史和当前题目，学生ID、当前及未来答案留在评价侧。

模板可配置结构化instructions、state_layout、history_encoding、reference_mode、positive_class和question_key。表格历史含列名并保留原始ID类型、知识点数组及对错；recover_facts逐条恢复验收。训练先验来自其他训练折，不纳入开发学生。固定odds参考不是模型预测，不是用开发标签拟合的新模型；其离线诊断独立存档offline_reference/reference.json。

4并发、240RPM是本地调度参数，并非官方额度。每次HTTP端到端期限30秒，每目标最多2次尝试。超时可能已被远端计费，失败无费用元数据时保留预留。预算保护停止新请求并排空在途，不能把未完成轮当成完整比较。

## 冻结、评价和选择

每轮先冻结假设、完整config、全部payload哈希、数据哈希与源码身份；全部492事实恢复验收通过才执行。每轮只使用该轮全新远程响应，不导入旧预测。本地缓存用于追溯与恢复，不假定供应商给Jev缓存输入折扣。

预设开发门槛：相对原Jev整体AUC至少+0.005，学生mean下降不超过0.005，Log loss增加不超过0.02，单学生最大AUC下降不超过0.04。满足门槛的候选按整体AUC选择，优先完整复跑；重复不作新prompt候选参与选择。这个门槛不是统计显著性或总体非劣性证明。

每轮保存请求、原始响应、实际HTTP输入、attempt、invocation、配置、预测、逐学生指标、机器reflection与中文复盘。负事件原noul保留，输出p_correct=1-p_incorrect并记录转换。阶段final_acceptance独立按正负样本配对重算每名学生AUC，核对所有账本attempt与费用预留。原始数据和运行文件均留在Git忽略目录。

每轮报告所有结果，包括失败方向，不删除不利结果。最终建议需结合完整复跑和原模板对照，不能只挑最高AUC。未执行大验证集，所有结论属于4学生开发集。
