# LLM-KT 工作简报（第二版）

更新：2026-10-24；包含KT适配、效果优化、降本优化及正反问法的两轮验证。

本项目将知识追踪（KT）统一为：给定学生此前真实作答及当前题目，预测本次答对概率。语言模型与决策模型共用数据协议和评价流程，分别设计输入与输出适配；不训练模型参数，不将上一步预测代替真实历史。

## 两条技术路线

**语言模型版（Qwen）**：通过Chat接口，把历史作答、当前题目和统计证据组织成提示词，让模型输出答对概率。改进重点是从“直接读历史”走向“学生近期状态＋知识点掌握＋训练集题目难度”，再通过无损历史编码和直接小数输出降低token开销。

**决策模型版（Jev）**：通过Decisions接口，把合法事实组织为state，用一个明确的二元问题直接获得noul概率，无须生成文本答案。改进重点是将事实整理为决策卡、由代码计算数值参考、使用无损表格历史，以及改问“是否答错”后转换为答对概率，使任务表达更贴合结构化决策。

共同工程改进包括：配置化切换模型与模板、训练先验隔离、并发与超时控制、预算保护，以及输入输出和中间产物的缓存、哈希与唯一追溯。

费用统一为完成一次完整验证任务（4学生、492目标）的费用，不按200长度序列折算。具有首次／复跑两轮的新增方法，费用与耗时分别取两轮均值；历史单次版本保留实测值，同向集成按两次调用合计。费用为已知收费，未知费用另列“＋…预留”，美元×7换算；三种正反公式共享请求，不重复累计。

完成耗时为各次实际推理invocation的累计运行秒数，含重试、恢复及程序内等待，不含人工排查停顿、离线评估和文档整理；正反／同向集成按本实验顺序执行的两组运行时长相加，不代表未来并发部署的最短延迟。Jev初始适配含一次异常长尾，保留原实测耗时。

## 当前结论与下一步

正反问法的思想是对同一目标分别预测答对概率a和答错概率b，再融合。表中的概率平均为(a+1-b)/2，logit融合为sigmoid((logit(a)-logit(b))/2)，支持归一化为a/(a+b)。第二轮保持模板与公式固定、反转正反执行顺序；同向集成也使用两次请求作对照。

**保留Qwen的R2省token版及Jev的第4轮单向反问版。** 正反融合的两轮实验未显示整体AUC优势，请求数却翻倍，暂不设为默认；Jev的小幅校准改善可作为后续研究线索。

Qwen当前更省钱、学生AUC均值更高；Jev整体AUC略高。整体AUC混合全部目标，学生mean先在各学生内部计算再等权平均，应分别解读。

正反阶段完成8组完整推理、3936成功预测。已知费用￥1.6109，31次未知费用预留￥0.1434，合计￥1.7544，低于人民币3元，已停止付费。原始概率重放、176项学生AUC与44项整体AUC独立复核通过，60项离线测试通过；缓存、失败、恢复及费用均可追溯。

全部表格使用同一NIPS开发集：4学生、每组492完整目标，4/4学生AUC有效，std为样本标准差。开发集已反复使用，尚不能证明总体或独立测试优势。Qwen使用自报数值概率，Jev使用原生noul；本轮未验证Qwen的yes/no token logits。正反一致不等于真正无偏，固定代码参考AUC约0.79205也提示仍需检验模型的额外价值。
