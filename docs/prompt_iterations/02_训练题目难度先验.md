# 第二轮：训练题目难度先验

## 假设与变更

R1 AUC 0.767998，仍不能从不透明题号识别题目难度；当前验证目标均没有该学生的同题记录。加入训练群体的题目/知识点先验，让模型结合题目难度与个人准备程度，而不是只看平均对错率。

版本：configs/prompts/round2.yaml，kt_r2_training_difficulty_v1。先验只从原 NIPS 训练验证文件的 fold1–4 构建：3148名学生、887776次作答；排除 fold0 的787名学生，不读取独立 test 标签。采用强度20的平滑，来源哈希与配置冻结在本地先验产物中。

这是“训练信息增强＋提示规则”迭代，不是只替换同一输入上的几句话。未改变当前学生的可见历史窗口。

## 总结与复盘

R2 相对 R1 AUC 增加0.030243，相对 B0 增加0.060692，保留为当前最佳。logloss与Brier也下降，但0.5阈值的准确率下降；本任务优先AUC，不据此回退。学生均值改善，但仍仅16名可计算学生，结果易波动。

题目先验单独作为评分的验证AUC约0.687664，低于R1；组合后的增益不能理解为“简单复制题目平均正确率即可”。

残余问题：提示要求模型自由融合概率，可能出现重复计算信息或粗略算术。作为诊断，固定将训练题目 log-odds 加上近期与总体准备度相对群体的偏移，一个未经学习的0.7/0.3参考规则在当前验证集AUC约0.820513。该诊断参与验证集迭代，不是独立结果。

下一轮保留完全相同的历史、计数与训练先验，只将自由融合改为明确的概率组合步骤，检验更精确、可复现的数值提示是否优于宽泛语言指令。必须将其报告为有明确数值先验的提示方案，不宣称为大模型自行发现的规律。

本轮未使用测试标签选择候选，也未进行token节省优化。
