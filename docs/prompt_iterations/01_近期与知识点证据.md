# 第一轮：近期与知识点证据

## 假设与变更

基线在完整 fold0 验证集 AUC 为 0.737549，存在概率扎堆、0/1 极端值，以及长历史组排序较弱的问题；可见历史最近10条对错率的简单参考 AUC 为 0.768080。第一轮保留完整历史，补充确定性计数摘要，明确近期、当前知识点和小样本收缩规则，要求连续概率并保留不确定性。

版本：configs/prompts/round1.yaml，kt_r1_visible_evidence_v1。同一 Tenstorrent fp4、同一221目标、同一合法真实历史。摘要全部由当前请求允许的历史计算，没有外加训练标签或未来信息。

## 总结与复盘

R1 相对 B0 的 AUC 增加 0.030449，长历史组从 0.702047 到 0.743939，中等历史组从 0.674769 到 0.729745。概率唯一值从28增至108，logloss下降，说明提示与摘要对当前验证样本有效。保留为当前最佳。

学生级均值没有改善，有效学生只有16名，不能把整体增益解释成普遍的学生级增益。单个小验证集上也不能宣称统计显著。

残余问题：当前题全部没有学生自己的同题作答记录，模型只能依赖知识点和总体行为。未见知识点组的平均预测0.5678，而正例率0.3462，存在偏乐观。仅靠题号本身不能识别题目难度。下一轮使用严格训练集来源的题目/知识点难度先验，检验是否补充信息，而非把题号大小当语义。
