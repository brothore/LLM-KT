# 基础版本实现与验收

版本：v0.1，2026-10-17。设计文档仍描述完整目标，本文件记录当前实际交付边界。

## 当前可运行链路

`import-pykt → prepare → validate/dry-run → infer/resume → evaluate → compare`。

项目使用 Python 包与命令行，没有运行时依赖相邻的 pykt 仓库。源码中的数据协议与学生统计复用均位于本项目，来源副本和 MIT 许可位于 `third_party/pykt`；复制函数、提交与哈希见 `provenance.json`。

核心模块是 `config/data/protocols/domain/providers/runtime/evaluation/cli`。当前采用单包模块划分，便于基础版本阅读与维护，后续规模增加时可在接口不变的条件下拆分子包。

## 数据与协议边界

当前导入完整原始学生序列文件，不导入预先生成的窗口/分段文件。每名学生一行，以 UID 和原始事件位置生成身份，不依赖旧预测文件里的累加计数。

题目原生表示可多知识点；概念级模式限单知识点。概念展开输入可按 is_repeat 合并，首版仅开放完整前缀协议，避免错误宣称等价于上游题目专用窗口。

题目原生 CSV 上的窗口/分段目标与项目内复制的 pykt `split_datasets_que.py` 生成函数做直接对照，覆盖长度 2、3、199、200、201、400。对全是过短片段而没有输出的情况，上游函数存在缺列异常；本项目明确返回空目标并在 prepare 时报告无可预测目标。

已有训练验证 fold 可配置选择，并检查学生跨集合问题。为新原始日志清洗、按比例生成新 fold 和特定数据集自动定位，尚未实现。

## 模型与执行边界

已实现 Decisions Noul/Choice 和 Chat JSON 概率适配。当前通过模拟 HTTP 验证请求/解析和 429 重试，未调用付费模型。实际模型支持的参数和最终响应还需真实小样本确认。

调度具备并发、RPM、每次命令的请求尝试次数上限、每目标累计重试上限、SQLite 持久化、单运行目录进程锁及成功结果复用。缓存限于当前 run；不同 run 不共享成功响应。

美元预算、token 预算、模型能力自动发现、上下文 token 校验、流式推理、模型训练、few-shot 和多步递推不在当前版本内。配置严格拒绝未实现字段，避免配置已写但不起作用。

## 指标边界

标准指标包含整体与学生级 AUC、ACC、LogLoss、Brier，学生 AUC mean/std/median/range/IQR 及覆盖率。单类 AUC=null，默认 ddof=1，只有一名有效学生时 std=null。

历史模式包含二次滑窗汇集、单类赋值 0.5、ddof=1、Gini/EAWI。它只复用历史统计规则，不自动复现原模型隐藏状态融合、输出舍入或旧预测文件身份问题。新模型概率不做四位舍入。

多运行比较检查相同 task_id 和输入哈希，配置指标口径也须一致；不完整结果只比较共同成功目标并标记探索性。尚不包含 bootstrap、配对显著性检验和历史基线文件导入。

## 验证方式

测试采用 unittest，使用合成学生序列与模拟 HTTP，不访问网络。检查未来/当前标签隔离、允许历史变化、稳定目标身份、pykt 原函数边界对照、训练验证折和学生隔离、概率错误、已知 AUC、单类学生、请求限额及恢复。

本次验收：12 项测试通过；无密钥 CLI 演示成功生成 3 名学生、10 个目标的预测与报告；重复 resume 新增调用为 0。项目本地 wheel 已构建成功，包含 vendor MIT 许可。

项目内 `configs/demo.yaml` 可完成无密钥演示。演示使用历史正确率平滑的 Mock，不能作为模型性能结论。真实数据推理前先按 README 导入数据、查看 dry-run，再设置密钥执行。
