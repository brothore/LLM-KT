# 完整学生预算子集（2026-10-18）

用户要求保持一次完整推理费用的原有规模，同时完整预测选中学生的序列。新版本 `nips_complete_students_budget_v1` 按学生选择，未调用付费 API。旧 `nips_task34_0p1pct` 保留以追溯历史结果，退出正式评估。

## 完整性的定义

每个学生复制原始 CSV 完整一行，保留原 split/fold。从第二次作答开始，所有时间步均生成预测目标，无 `selection.jsonl`、无目标截断。每一步使用此前真实作答；当前标签仅进入评估文件。沿用 `pykt_window`，历史最多199条，但长序列后续时间步仍全部预测。完整评价序列和无限历史上下文是两个不同概念。

## 同等费用下的选择

以此前 Qwen3.8 27B / Tenstorrent 的一次 split 完整推理费用为约束，同时检查基线和 R2。fold0 原基线为 $0.011493208，R2 为 $0.013202960；test 原基线为 $0.014253580，R2 为 $0.016164480。其他 fold 没有实测整轮费用，按旧目标数相对221的比例设定参考上限，不能当成实际账单。

每fold选择两名不同学生。先按原序列长度排序，同长度用 seed42 的 SHA256排序；尝试长度25%和50%分位对应的学生。若估算超出任一prompt预算，同时将两分位乘以递减系数，每次降低0.025，直到符合预算。选择不查看标签、预测或AUC。选后才检查正负目标及AUC可计算性，不因结果不好重新抽取。

这是**预算约束的长度分位选择，不是随机等概率抽样，也不具备总体代表性**。选择两人是在每人目标数量和学生数量之间的明确折中，没有宣称为数学最优设计。原总体序列中位数约240，当前预算下两人方案偏向短序列，不能覆盖长序列和滑窗滚动阶段。

选后检查发现，fold0验证目标96正/134负（41.74%正确），测试197正/65负（75.19%正确）；原总体分别约53.12%、54.96%。小规模按长度选择不能保证标签比例接近总体，本版保留这一差异并明确记录，没有根据标签反复换人。这进一步限制了结果的外推范围。

## 成本估计口径

完整渲染每个目标的基线与R2请求，使用旧验证运行的实测字符/token比率换算，并将输入token增加25%。输出每请求至少预留32token（若实测均值更高则取均值）。使用项目内2026-10-18价格快照：输入 $0.02/M，输出 $0.5/M；不假设缓存折扣、不依靠本地旧结果减少费用。

估计不是付费承诺：模型输出长度、分词和价格变化、重试都可能改变账单。实际执行仍须使用持久化预算账本；若额度不足应暂停，不得静默丢弃剩余时间步并把不完整结果当作完整评估。本轮只准备数据，没有授权或执行新付费运行。

其他fold的R2估算只用现有fold0先验作为输入大小代理；不能直接用该先验预测其他验证fold，因为其中可能包含其标签。其他fold正式使用训练先验前必须分别排除该fold重建。当前只配置fold0和test实验。

该集合用于低成本完整KT流程及初步对比。若目标是稳定学生级研究，必须另行增加学生数量和长度覆盖，不能沿用旧费用承诺总体代表性，也不能把更多同一学生时间步当成更多独立学生。
