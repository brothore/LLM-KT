# KT正反问法对称融合：设计与执行状态

2026-10-19。用户授权人民币3元探索Jev与Qwen。方案和实现已准备，57项离线测试通过。用户在明确数据发送范围后回复“开始”，现已获全量发送授权并启动第一轮。完成情况以本阶段账本和结果为准。

## 启发与任务区别

启发来自GraphGen，https://arxiv.org/html/2505.20416v1#S4 的理解评估与式(3)：将肯定陈述的yes信心与否定陈述的no信心平均。原论文衡量已知真实知识点的理解；本任务预测尚未观测的学生作答，标签仅在评价时使用，不参与选取输出类别或融合。这里是改造后的实验，不是论文方法的直接复现。

令a=P(答对|正问)，b=P(答错|反问)。两次独立请求读取相同合法事实，不在同一聊天中暴露另一问的回答。模型可见内容不包含学生ID、当前及未来标签。

## 冻结公式

1. 算术平均：p=(a+1-b)/2，作为最接近原论文思想的参照。
2. 主方法logit相消：p=sigmoid((logit(a)-logit(b))/2)。仅为数值稳定将输入裁剪到[1e-6,1-1e-6]。
3. 支持归一化：p=a/(a+b)，a=b=0时约定0.5；作为附加敏感性比较，不认为与前两者具有相同统计含义。

如果logit(a)=s+c，logit(b)=-s+c，即两种问法有相同加性yes偏好c，主方法恰好得到sigmoid(s)。偏好不同、否定理解错误、共享信息偏差都可能破坏假设，所以称极性对称融合，不宣称真正无偏。若偏好在整个数据集是常量，单向logit平移本身不改变AUC，可能只改变校准；需同时看AUC、学生mean/std、Log loss和Brier。

## 对照与预算

同一4学生492完整目标，两轮正反配对，各模型共4次完整推理。第二轮反转正反派发顺序。每对同时评估正问、反问补概率、三种融合；两轮后对比同方向重复平均（两次请求）和每次正反融合（两次请求），防止把普通集成收益误认作去偏。另报告四请求合成，两倍成本单列，不与两请求方案假装等成本。

问法分歧d=a+b-1，报告均值、平均绝对值和P95；另报告logit偏移代理，不把这些诊断当作可识别的真实偏差。权重和公式不按开发标签拟合，不扫描标签驱动的权重。

Jev是原生noul；Qwen当前使用模型输出四位小数概率，而非yes/no token logits。两者都保留原始响应，并由适配器将反问输出统一为p_correct；融合时显式恢复原生反问事件概率b。该差异必须在报告中保留。

独立账本runs/complement_20261019_v1/budget.json，上限3/7美元，按美元×7规划。每次尝试预留，未知费用不释放；完整轮启动前保守准入，不允许超预算或仅挑共同成功子集作正式结论。旧Qwen/Jev账本不改变。

对照补充（第二轮执行前）：同方向重复同时计算算术平均和logit平均，分别与正反的对应算子比较，避免把融合算子差异混入问法收益。该补充不增加请求、不拟合参数。


解释补充：对任意a、b都可以形式上写s_hat=(logit(a)-logit(b))/2、c_hat=(logit(a)+logit(b))/2。这只是两观测的代数分解，不能从中识别c_hat一定是真实回答偏差。a=0.9、b=0.1时完全互补，但若真实风险为0.5，三种融合都不能自动纠正共有错误。两次询问共享同一历史证据，不能把它们当独立证据直接相乘odds；主公式中的1/2用于平均证据强度。
