# 数据代表性与既有迭代的纠正审查

2026-10-18。用户质疑大量学生AUC不可计算、抽样代表性与迭代可信度后进行离线复查。没有调用付费模型，没有删除或重写旧数据与原始实验结果。

## 需要纠正的结论

现有0.1%目标抽样子集不适合稳定评价学生AUC mean/std。以该指标作为组件改进、学生群体能力或公平性证据的表述均不成立。旧整体AUC保留为特定小样本上的探索性数值，不作为已证实的稳定模型收益。R2没有独立测试AUC增益，不应固定为最佳方案。

实现者在抽样前未把学生级评价的可计算性与稳定性设为验收条件，后续也没有在主要结论中充分解释低覆盖率的严重性。这是实验设计和汇报上的失误，不能以评价公式正确或抽样单位曾获确认来替代对实验目标的负责。

## 不可计算的具体原因

学生AUC要求该学生的评价目标里至少有一个真实正例和一个真实负例，并有相应预测概率。与输入历史太长无关；通常是抽到的评价目标太少。保留该学生完整历史作为上下文，不等于已预测全部历史事件。

| 已抽样学生的情况 | validation fold0 | test |
|---|---:|---:|
| 总学生数 | 179 | 228 |
| 只抽到1个评价目标 | 141 | 189 |
| 抽到多个，但真实标签全同类 | 22 | 25 |
| 能计算AUC | 16 | 14 |
| 有效学生覆盖率 | 8.94% | 6.14% |
| 学生内部正负目标配对总数 | 19 | 17 |

验证集有效16人中13人只有2目标，3人只有3目标。R1为8人AUC=1、8人AUC=0，所以mean=0.5。standard_v1没有将其他163人补成0.5，而是输出null并从均值中排除。逐正负对排序的独立复算与代码一致；数学正确不能补救只有少量有效学生的评价设计。

## 抽样到底代表了什么

抽样实现按fold、标签、历史长度档、是否多知识点分层，再使用固定seed哈希选目标。它主要约束这些边际分布，没有保证学生内部评价目标数量、正负类别、题目难度分布或学生群体代表性。

验证标签正例率：原总体53.12%，子集52.94%；测试原总体54.96%，子集54.78%。这说明标签比例接近，不能推出学生级评价也有代表性。

验证当前目标覆盖187/932种题目、42/57种知识点；测试覆盖227/919种题目、39/56种知识点。小样本无法覆盖所有类别本身不证明抽样必然错误，但这些数字未构成对题目频率、难度和尾部学生群体分布的完整验证，不能据此宣称全面代表性。

学生层面有实际选择效应：序列较长的学生更容易抽到多个目标，并进入可计算AUC的群体。有效验证学生原序列长度中位数550，其他已抽样学生为356。由这16人计算的mean不能代表全部179人，更不能代表原验证fold的787人。

## 对三轮迭代的影响

1. 学生mean/std非常不稳定。16人的19个内部正负配对，不足以支持学生层面的组件收益结论。
2. 整体AUC不是自动作废，但只描述221/272目标小样本。多个同学生目标还可能相关，不能把所有正负配对数量当成独立样本量。
3. prompt迭代只在一个抽样seed、一个验证fold上选择，没有独立生成重复响应来测量模型输出波动。验证集参与设计和选择，存在选择乐观性。
4. R2同时改变了训练先验信息和提示规则；不是干净的单因素消融，不能把增益全归因于措辞或某一先验。
5. R2独立测试AUC为0.766683，基线0.777541；测试差的学生聚类bootstrap区间约[-0.05362,+0.03188]。未证明提升，也不能将小幅负差解释成稳定退步。
6. 之前建议直接在同样子集上开展两fold五组消融，仍不能解决每学生目标过少的问题。它只增加了类似抽样的次数，没有完成学生级评价验收；不应按原计划继续付费。

## 已复核的完整性与其他已知限制

- 493条验证/测试目标标签、当前题和完整合法历史与父序列逐条一致，未发现标签错位或当前/未来响应进入模型输入。
- 从原训练fold1–4重新构建先验，与实际R2先验精确一致；排除validation fold0，未用test标签生成先验。这只是对项目可见数据流的核查，不是对黑盒模型训练过程的证明。
- 旧试验中的“完整”指跑完抽样221或272目标，不是对完整原始NIPS做了全量推理。
- 基线因本地写盘失败中断过；已成功返回的一条结果离线恢复，其他未完成目标补跑。7个无响应尝试费用未知，预留0.010898560 USD，不是全部成本都已精确确定。
- Tenstorrent使用fp4、Chutes使用fp8，便宜对照不等于质量等价；温度0也没有通过重复全量运行证明预测完全确定。
- 前缀缓存节省来自少量连续目标实验，不能直接用于整个稀疏抽样子集。当前runtime同学生目标还会并发，实际调度与缓存探索不同。

## 修复顺序

先明确估计对象，再抽样验收，不能先调用API、看到指标后才解释可用性。

整体预测评估与学生内部排序评估应分开设计、版本化并报告适用范围。学生级评估需选较少学生，对其完整或足够长的合法连续目标推理，保持真实标签分布；不能为凑双类或抬高均值反复按答案筛学生、平衡目标或给单类补0.5。

固定272个目标预算时，“覆盖228名学生”和“让多数学生有足够多的评价目标”不可能同时满足；若每人约20–50个目标，只能覆盖约5–13人，仍不足以形成可靠的全体学生mean结论。需要在学生数、每学生目标数、类别配对与预算之间明确权衡，不能再无条件承诺极小样本可代表所有目标。

新方案须在离线审查中报告父数据与子集的学生数量、每学生目标数、双类覆盖率、有效学生数、内部正负配对、序列长度/历史长度、题目/知识点频率、标签比例及预先固定的排除规则。若关键指标不可估计，先拒绝作为该指标的研究数据，而不是继续收费迭代。

本次没有擅自替换旧数据或发起新推理。详细统计在忽略目录 `data/reports/subset_validity_audit_20261018.json`。
