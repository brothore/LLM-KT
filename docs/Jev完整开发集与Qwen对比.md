# Jev完整开发集与Qwen对比

2026-10-18，用户明确批准Jev当前独立R2适配版本的完整评估，总预算约￥0.65，比较已完成的Qwen baseline、R2及R2省钱版。仅执行本轮Jev，不重跑Qwen、不调用大验证集、不扩展prompt迭代。

## 样本与协议对齐

四组使用相同4名学生、相同492个目标、相同task/sample身份和标准评估口径。每个学生从第2次作答至最后一次全部预测，使用此前真实作答，最多199条历史；没有时间步抽样，没有用预测填充历史。覆盖率492/492，4/4学生均有正负目标、可计算AUC。

Jev使用 `typesafe/jev-1.14`，固定TypeSafe、不回退，独立 `configs/decisions/jev_r2_v1.yaml`，noul直接作为概率。它与Qwen R2、省钱版共享全部合法历史和原训练fold1–4先验，接口及问题措辞独立；Qwen baseline没有R2训练先验，因此只是基础参考，不能把所有差异归因于模型。

本轮使用4并发、本地120 RPM、每目标最多2次尝试、每次命令最多984次尝试，参数冻结于run的plan。该限速是本地调度选择，不是官方限额。没有导入两条冒烟预测或旧Jev结果。
